รายการตรวจรับ

ผ่านการตรวจภาพและหลักฐานอัตโนมัติของชุดต้นแบบ

  • HUD ร่วมกัน พร้อมดาวสามแฉกและขากบสามนิ้ว
  • ไม่มีเป้หนัง รอยเท้าคน หรือเหรียญบนการ์ดกลับบึง
  • ข้อความเทียบตรงกับตารางในสัญญา Atomic 05
  • ดวงตาอยู่ในแถบปลอดภัย และไม่มี UI ทับใบหน้า
  • การ์ดใช้ Component ชุดเดียวกันบนทั้งสองอุปกรณ์
  • ไม่มีภาพเสีย ไม่มีข้อความล้น และเก็บ v1 เดิมครบ
