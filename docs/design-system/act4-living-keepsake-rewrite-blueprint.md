## 0. หน้าที่ขององก์นี้

1. รวมทีมห้าฮีโร่ เมื่อพี่กับกับน้องกิบโผล่ขึ้นมาจากคลองคู่ขนานตรงกับที่รหัสเคาะท่อบอกมาตลอด
2. ดราม่าที่หนักที่สุดของเรื่อง: แมลงสาบแมนแฉคำอธิษฐานของเสื้อ พี่กับรู้ว่าน้องอาจไม่ได้กลับบึง แล้วยอมเป็นฐานส่งน้องขึ้นไปเอง
3. ฟิ้วก้าวข้ามเสียงฟ้า ฝากริบบิ้นกลิ่นแดด แล้วกางปีกเต็มที่เป็นครั้งแรก
4. แยกเป็นสองแผนบุกที่ใช้ฟิสิกส์ต่างกันจริง แผน A ไต่ต้นไทรแล้วไถลตามเชือก แผน B ไต่ท่อรางน้ำแล้วดีดตัวจากกันสาด ทั้งสองแผนประสานกับลำไฟฉายของเตื๊อกจากนอกรั้ว

## 3. บท

### A4-01 · สวนหลังบ้านที่มืดสนิท
`mode: vn` `bg: bg_act4_garden_brick_wall` `cg: —` `silence: 2s` `stage: ฟ้าแลบกับฟ้าร้องเกือบพร้อมกัน (ไม่ถึง 1 วินาที)` `effect: ถ้ามีธง fiw_trusted สายใยเจ้าฟิ้ว +1`
> บรรยาย: หลังรั้วสังกะสีบานที่สาม คือสวนหลังบ้านหลังคาสีครีม ทั้งบ้านมืดสนิท เว้นหน้าต่างชั้นสองบานเดียวที่ยังมีแสงริบหรี่
> บรรยาย: ฟ้าแลบ เสียงฟ้าร้องตามมาทันทีโดยไม่ทันนับ พายุอยู่เหนือหัวพอดี
> ฟิ้ว: เดี๋ยวนะ ต้นไทรต้นนั้น ราวตากผ้าเส้นนั้น
> ฟิ้ว: ฟิ้วเก็บผ้าพันคอผืนนี้ได้ที่นี่ หน้าร้อนที่แล้ว มันปลิวมาจากหน้าต่างบานนั้น
> บรรยาย: ผ้าพันคอสีเหลืองที่คอฟิ้วสะบัดตามลม ปลายผ้ามีรอยยับเป็นวงเล็ก ๆ เหมือนเคยถูกผูกเป็นโบว์
> {fiwtrusted} ฟิ้ว: นายขอให้ฟิ้วนำทาง ฟิ้วก็นำมาถึงจริง ๆ นะ
> {fiwtrusted} บรรยาย: เธอยืดอกขึ้นนิดหนึ่ง เป็นครั้งแรกตั้งแต่ได้ยินเสียงฟ้าคืนนี้

### A4-02 · ฝาท่อสวนที่เด้งเอง
`mode: vn` `bg: bg_act4_garden_brick_wall` `cg: —` `silence: 3s`
> บรรยาย: ฝาท่อระบายน้ำขอบทองเหลืองที่มุมสวนเด้งขึ้นเอง น้ำพุ่งตามมาด้วยกบสองตัวเปียกโชก
> กับ: ปึก-ปึก! ใครบอกว่าคลองนอกมันสั้น โกหกทั้งนั้น
> กิบ: กิ๊บ-กิ๊บ! พี่กบ! กิบวางเมล็ดไว้ทั้งทาง พี่เห็นไหม
> กบ: เห็นทุกเมล็ด
> บรรยาย: กับเคาะหัวน้องชายเบา ๆ หนึ่งที กิบกอดแขนพี่กบไว้ไม่ยอมปล่อย
> กับ: ข้าบอกแล้วว่าจะได้ยินเอ็งก่อนได้ยินฝน
> บรรยาย: เศษเมล็ดต้อยติ่งที่ติดตัวกิบยังเรืองแสงจาง ๆ ทั่วตัว เหมือนเธอเพิ่งว่ายผ่านทางช้างเผือกมา
> ก้าม: ครอบครัวแกเหรอ เสียงดังเหมือนกันหมดเลย
> ฟิ้ว: ห้าคนแล้ว! ห้าคนก็เป็นทีมได้แล้วนะ

### A4-03 · กำแพงสูงสองเมตร
`mode: obstacle` `bg: bg_act4_garden_brick_wall` `cg: —` `silence: 1s` `physics: กำแพง 2.0 ม. กระโดดสูงสุด 1.02 ม. แม้ใช้ดีดตัวผ่าลม จึงต้องไต่`
> บรรยาย: กำแพงอิฐสวนสูงสองเมตร สูงกว่าเจ้ากบสี่เท่า กระโดดอย่างไรก็ไม่ถึง มีเถาไอวี่เกาะขึ้นไปตลอดแนว ใบเปียกลื่น
> กับ: ข้ายืนเป็นฐานให้ เอ็งเหยียบบ่าข้าขึ้นไป
1. **ก · ดีดตัวผ่าลม · ดีดตัวจากเถาหนึ่งไปอีกเถา** · ผล: ทักษะครอบครัว
   > {wall:skill} บรรยาย: เถาไอวี่เป็นบันไดที่ขยับได้ เจ้ากบดีดตัวขึ้นทีละช่วง ไม่ให้เถาไหนต้องรับน้ำหนักนานพอจะขาด
2. **ข · ให้พี่กับเป็นฐานส่ง** · ผล: การพึ่งพี่น้อง (นับเหมือนทักษะครอบครัว)
   > {wall:kab} บรรยาย: กับย่อตัว เจ้ากบเหยียบบ่าพี่แล้วถีบตัวขึ้น มือคว้าเถาช่วงบนได้ ครึ่งกำแพงที่เหลือเขาไต่ต่อเอง
3. **ค · ให้ฟิ้วไต่นำ ชี้เถาที่เกาะได้** · ผล: สายใยเจ้าฟิ้ว +1
   > {wall:friend} บรรยาย: ฟิ้วไต่ขึ้นไปก่อน ใช้หางชี้เถาที่แข็งแรงทีละเส้น เจ้ากบไต่ตามจุดที่หางเธอชี้จนถึงสันกำแพง
   > {wall:friend} ฟิ้ว: เส้นนั้นไม่ได้ เส้นนี้ได้ ฟิ้วดูเถาไม้เป็นตั้งแต่เกิด
4. **ง · ยืนหยัดเอง · ไต่เถาไอวี่ขึ้นไปเอง** · ผล: แรง −1 · ต้องมีใจ ≥ 3
   > {wall:alone} บรรยาย: เขาไต่ขึ้นทีละมือ นับใบไม้แทนนับความสูง จนมือข้างหนึ่งแตะอิฐที่สันกำแพง
5. **จ · ฝืนเอา · กระโจนคว้าเถาที่สูงที่สุด** · ผล: กาย −1 · แรง −2
   > {wall:grit} บรรยาย: เถาขาดเส้นหนึ่ง เขาร่วงลงมาครึ่งทาง ก่อนอีกมือจะคว้าเถาเส้นที่สองไว้ได้

> แมลงสาบแมน: ไม่ได้กลับไปโดดน้ำกับพวกแกอีกเลย

| พักบนง่ามไม้ / พักบนกันสาด | เขาหอบหายใจสามครั้งตามจังหวะฝน แล้วมองขึ้นไปใหม่ |
| ตั้งสติฟังฝน | ฝนเบาลงหนึ่งอึดใจ เขารู้ทันทีว่าเงาไหนเป็นของจริง |
| ดีดตัวผ่าลม | ดีดตัวขึ้นหนึ่งช่วงเต็ม ตัดฝูงเงาขาดเป็นแนว |
| ตาส่องเงามืด | ประกายเล็ก ๆ ในฝูงเงาบอกว่าตัวจริงซ่อนอยู่ตรงไหน |
| สปริงพี่ใหญ่ | กับย่อตัว ปึก-ปึก แล้วส่งน้องขึ้นไปพ้นแรงฟาด |
| ห่าเมล็ดเรือง | กิบยิงกระบอกเมล็ดขึ้นฟ้า แสงเขียวทองแตกเป็นดาวกลางฝน |
| เมล็ดต้อยติ่ง | เมล็ดแตกกลางสายฝน แสงเขียวทองส่องให้เห็นฝูงเงาที่ซ่อนอยู่หลังม่านน้ำ |
| สนับข้อมือ | เปลือกไม้รับแรงฟาดกลางลมกรด เจ้ากบไม่ไถลถอยหลังสักคืบ |
| เฟืองสังกะสี | เฟืองขัดเข้าล็อกพอดี ไม่มีอะไรไถลถอยหลังอีก เพลงสามโน้ตแว่วอยู่ในเสียงลม |
| กระดุมทองเหลือง | เขาเอียงกระดุมรับลำไฟฉายเตื๊อก ดวงแสงสีทองเด้งขึ้นไปบนชายคา ฝูงเงาแตกหนี |
| ริบบิ้นกลิ่นแดด | กลิ่นแดดจากริบบิ้นลอยมาในลมฝน มือที่ชาเริ่มกลับมามีแรง |
| นกหวีดเรียกลำแสง | เสียงนกหวีดลอยข้ามรั้ว ลำไฟฉายเตื๊อกตอบกลับมาทันที |
| ผ้าพันคอนำลม | ริบบิ้นสะบัดบอกทิศลม ฟิ้วร่อนตามมันได้โดยไม่ต้องเดา |
| ล็อกท่อรางน้ำ | เฟืองขัดขายึดท่อ ก้ามหนีบล็อก ท่อหยุดสั่นทั้งเส้น |
| ลำแสงสัญญาจากนอกรั้ว | เตื๊อกยกไฟฉายสูงสุดแขน ลำแสงตัดฝนขึ้นไปถึงชายคา |
| โล่กระป๋องเหล็กคู่ใจ | พี่ก้ามยกกระป๋องขึ้นรับผ้าคลุมแทน เสียงสังกะสีดังลั่นแข่งกับฟ้าร้อง |
| โฉบคว้ากลางเวหา | ฟิ้วโฉบตัดหน้าลมกรด คว้าชายผ้าคลุมกระชากออกจากแนวที่เขาไต่ |

### A4-10 · ขอบหน้าต่างไม้
`mode: vn` `bg: bg_act4_windowsill_night` `cg: —` `silence: 6s` `rest: กาย 2 · ใจ 2 · แรง 2`
> บรรยาย: ขอบหน้าต่างไม้กว้างแค่ฝ่ามือ เจ้ากบยืนบนนั้นตัวเปียกโชก หลังกระจกคือห้องนอนที่มืดสลัว
> บรรยาย: บนเตียงกว้าง หญิงสาวคนหนึ่งนอนขดตัวคลุมโปง ผ้าห่มสั่นเป็นจังหวะ ข้างหมอนว่างเปล่า ไม่มีตุ๊กตาสักตัว
> บรรยาย: บนโต๊ะข้างเตียงมีโคมไฟถ่านดวงเดียว แสงริบหรี่ใกล้หมด
> บรรยาย: บนโต๊ะเดียวกันมีกรอบรูปเล็ก ๆ หันหน้าเข้าหาเตียง มืดเกินกว่าจะเห็นว่าเป็นรูปใคร
> บรรยาย: ดาวสามแฉกที่ชายเสื้อร้อนวาบ ร้อนจนเจ้ากบต้องกำมือ
> {plan:A} บรรยาย: ข้างหลัง ฟิ้วเกาะเชือกอยู่ที่กลอนหน้าต่าง กิบโบกมือจากกิ่งไทร กับกับก้ามยืนอยู่บนสันกำแพง
> {plan:B} บรรยาย: ข้างล่าง กับยืนเคาะสนับข้อมืออยู่บนกันสาด ก้ามยังหนีบท่อรางน้ำไว้ กิบกับฟิ้วเกาะชายคาอยู่ไม่ไกล
> กบ: เปี๊ยก
> บรรยาย: เขาพูดชื่อนั้นเป็นครั้งแรก เสียงเบาจนฝนกลบ

### A4-11 · บานเกล็ดที่แง้มไว้
`mode: vn` `bg: bg_act4_windowsill_night` `cg: —` `silence: 2s`
> บรรยาย: บานเกล็ดกระจกช่องล่างสุดแง้มอยู่ราวหนึ่งฝ่ามือ พอให้ตัวกบลอดได้
> บรรยาย: จากใต้ผ้าห่มมีเสียงฮัมเพลงเบา ๆ ลอดออกมา เพี้ยนนิดหนึ่ง และขาดเป็นช่วงทุกครั้งที่ฟ้าร้อง
> บรรยาย: เจ้ากบหันกลับไปมองทุกคนครั้งหนึ่ง กับพยักหน้า กิบชูนิ้วโป้ง ก้ามยกก้ามซ้าย ฟิ้วพยักหน้าตาม
> {fiw3} ฟิ้ว: ไปเลย กัปตัน
> บรรยาย: แล้วเขาก็สูดหายใจลึก มุดผ่านช่องบานเกล็ดเข้าไปในห้อง
