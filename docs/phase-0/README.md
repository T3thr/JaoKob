## การตีความระดับบังคับ

คำว่า "ต้อง" หมายถึงข้อกำหนดบังคับ คำว่า "ควร" หมายถึงแนวปฏิบัติที่เบี่ยงเบนได้เมื่อมีเหตุผลและบันทึกการตัดสินใจ คำว่า "อาจ" หมายถึงทางเลือก การใช้คำภาษาอังกฤษ `SHALL`, `SHOULD` และ `MAY` ให้มีความหมายเดียวกันตามลำดับ

หากเอกสารขัดกัน ให้ใช้ลำดับดังนี้: ข้อกำหนดเจ้าของโครงการที่อนุมัติแล้ว, SRS และ Architecture Blueprint, GDD และ Narrative Bible, JSON Schema, AI Agent Engineering Guide, เอกสารการปฏิบัติงาน ทั้งนี้ข้อขัดแย้งต้องถูกบันทึกเป็น change request ห้าม Agent เลือกคำตอบเองโดยไม่มีหลักฐาน
