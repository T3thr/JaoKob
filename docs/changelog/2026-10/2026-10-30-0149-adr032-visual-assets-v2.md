## 5. Verification Not Performed / Risks / Approvals

PNG ใหม่รวม 77,832,665 bytes, WebP 11,737,394 bytes เป็นคลังสำหรับ authoring ไม่ใช่งบโหลดเกมพร้อมกัน Runtime derivatives/loading policy ยังต้องวางในงาน integration ส่วน E-POND ใช้ฉากหลังบึงเดิม ไม่มี CG แยกที่ไม่ได้อยู่ในรายการสัญญา

คง **production WBS 0/20**; การทำ UX/camp/tactical/physical shadow ตาม ADR-033 ต้องตามสเปกและงาน implementation ภายหลัง Approvals ที่ยังต้องการ: **PO art review และ human PR review**

## 6. Scope / Migration / Rollback

Scope: ภาพต้นแบบ v2, comparison notes, manifest/provenance, gallery และ audit evidence. Non-goals: เปลี่ยนเรื่องหรือ canon, เปิด content/runtime, schema/save, mechanics, architecture, dependency, merge หรือ deploy

Migration: ไม่มี เนื่องจากไม่แตะ runtime หรือข้อมูลผู้เล่น Rollback: กลับไปเปิด manifest/gallery v1 เดิม หรือ reviewed revert เฉพาะ delivery นี้; ไม่แก้ saves หรือประวัติร่วม และไม่ลบงานที่มีอยู่ก่อน
