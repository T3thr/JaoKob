# Domain Events

**สถานะ:** โฟลเดอร์จองไว้ตามโครง Clean Architecture ยังไม่มีไฟล์

**ใส่อะไรที่นี่:** เหตุการณ์ของโดเมนที่ core ประกาศออกไป (เช่น ปมสายใยเพิ่ม ศึกจบ) ให้ adapter รับไปแสดงผล

**กติกา:** เป็น plain object ที่ไม่เปลี่ยนค่า ห้าม import จาก `src/ui/` หรือ `src/data/` และห้ามเรียก Browser API
