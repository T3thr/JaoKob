# UI Accessibility

**สถานะ:** โฟลเดอร์จองไว้ตามโครง Clean Architecture ยังไม่มีไฟล์

**ใส่อะไรที่นี่:** ตัวช่วยด้านการเข้าถึง เช่น การประกาศผ่าน `aria-live` การจัดโฟกัส และโหมดลดการเคลื่อนไหว ตาม WCAG 2.2 AA

**กติกา:** ทุกตัวช่วยต้องผ่านเกณฑ์ใน [interactive-gameplay-ux-ui-specification.md](../../../docs/design-system/interactive-gameplay-ux-ui-specification.md) §1.6
