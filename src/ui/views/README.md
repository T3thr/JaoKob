# UI Views

**สถานะ:** โฟลเดอร์จองไว้ตามโครง Clean Architecture ยังไม่มีไฟล์

**ใส่อะไรที่นี่:** หน้าจอระดับโหมด (เรื่อง ศึก แคมป์ สัมผัสโต้ตอบ ฉากจบ) ที่ประกอบจากชิ้นส่วนใน `src/ui/journey/components/` (ปัจจุบัน `src/ui/journey/journey-renderer.js` ประกอบทุกโหมดเองและยังไม่ต้องแยก view)

**กติกา:** view รับ view model ที่ไม่เปลี่ยนค่าจาก core เท่านั้น ห้ามคำนวณกติกาเกมเอง
